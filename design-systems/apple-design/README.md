# Apple Design (HIG-inspired)

An alternative design system for video-dashboard — SF Pro system typography, semantic system colors, Liquid Glass material, built to Apple's Human Interface Guidelines. Same page set as [Oceanic Design](../oceanic-design/) for direct side-by-side comparison.

**Status: first pass, not yet reviewed.** Built solo under full delegated authority. Look it over before treating it as final — it hasn't been through the iterative review Oceanic Design got.

## Contents

- **`DESIGN-SYSTEM.md`** — start here. Tokens, page-by-page spec, principles, and where this deliberately diverges from Oceanic's composition (and why).
- **`preview/all-pages.html`** — the **light** variant. Open directly in any browser, jump links at top.
- **`preview/all-pages-dark.html`** — the **dark** variant, with stronger/more visible glassmorphism and a reframed composition (floating pill nav, bento-grid dashboard, floating dock instead of a sidebar). Not a color-swap of the light file — a genuinely different layout. See DESIGN-SYSTEM.md for the full list of what changed and why.

## Two design systems, both safe

This lives alongside `design-systems/oceanic-design/` — nothing here overwrites or affects that one. Nothing in `src/` has been touched by either. Compare them, pick one later, or keep exploring more.
