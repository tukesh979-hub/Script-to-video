Fluent Design — Microsoft Fluent 2, built from research grounded in Fluent UI's actual GitHub tokens (spacing, radius, motion durations/curves confirmed exact) plus documented Fluent 2 conventions (materials, pillars, iconography). Deliberately different register from Oceanic/Apple: Segoe UI Variable, Semibold headings (never bold), tight 4–8px radii on real UI (buttons are NOT pills), dual-layer elevation shadows instead of glow, three distinct materials — flat bordered Card for content, blurred+noise-textured Acrylic for transient surfaces, flat tinted Mica for persistent nav — and a calm brand-tint CTA instead of a dark neon one. Same page set as Oceanic/Apple for direct comparison.
