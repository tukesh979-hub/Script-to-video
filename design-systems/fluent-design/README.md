# Fluent Design (Microsoft Fluent 2)

A third alternative design system for video-dashboard — Segoe UI Variable typography, tight 4-8px corners, dual-layer elevation shadows, and Fluent's three distinct materials (Card, Acrylic, Mica). Built from research grounded in Fluent UI's actual GitHub source (spacing/radius/motion confirmed exact) plus documented Fluent 2 conventions. Same page set as [Oceanic Design](../oceanic-design/) and [Apple Design](../apple-design/) for direct comparison.

**Status: first pass, not yet reviewed.** Built solo under full delegated authority.

## Contents

- **`DESIGN-SYSTEM.md`** — start here. What's confirmed from live research vs. documented knowledge, full tokens, page-by-page spec, and everywhere this deliberately differs from Oceanic/Apple (not just palette — buttons aren't pills, shadows aren't glows, nav isn't floating).
- **`preview/all-pages.html`** — open directly in any browser. Every page, working, jump links at top. Includes a lightweight approximation of Fluent's signature "Reveal" hover effect on the nav rail.
